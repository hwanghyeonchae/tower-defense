# NEON BASTION

마지막 코어를 지키는 브라우저 타워 디펜스 게임입니다. 별도의 빌드나 패키지 설치 없이 HTML, CSS, JavaScript로 실행됩니다.

## 실행

`index.html`을 브라우저에서 열거나, 이 디렉터리에서 정적 서버를 실행하세요.

```sh
python -m http.server 8000
```

브라우저에서 `http://localhost:8000`으로 접속합니다. 글꼴은 Google Fonts에서 불러오며, 연결되지 않으면 시스템 글꼴로 표시됩니다.

## 게임 구성

- 쉬움·보통·어려움 등급의 고유 맵 9개, 맵과 별도로 선택하는 전투 난이도 3단계
- 레벨마다 20웨이브, 5웨이브마다 보스와 무작위 능력 3개 중 하나를 고르는 보상
- 타워 7종: 펄스, 레일건, 프로스트, 노바, 테슬라, 베놈, 솔라 랜스
- 전체 타워 최대 12개 및 종류별 건설 한도, 최대 4레벨 강화, 판매
- 보스 체력 바, 단일 대상 이론 DPS, 배속, 일시정지, 사운드
- 브라우저 localStorage에 레벨별·난이도별 클리어 별점 저장

타워를 선택하고 길 바깥의 빈 지형을 클릭하면 건설됩니다. 건설된 타워를 클릭하면 강화하거나 판매할 수 있습니다. 새 레벨을 시작하면 현재 전투는 초기화되며, 클리어 기록은 유지됩니다.

## 조작

| 키 | 기능 |
| --- | --- |
| 1–7 | 타워 선택 |
| Space | 다음 웨이브 시작 |
| P | 일시정지 / 계속 |
| Q | 궤도 공격 |
| Esc | 타워 선택 해제 |

## 파일

- `index.html`: 게임 화면과 대화상자
- `style.css`: 반응형 UI 스타일
- `game.js`: 전투, 맵, 타워, 능력 보상 및 진행도 저장

정적 호스팅에서 그대로 제공할 수 있습니다. 이 저장소는 서버나 외부 계정 연결을 요구하지 않습니다.
